# DELTA-WEB 需求文档 v1.0

网页端 3D 第一人称撤离射击游戏（Delta Force 烽火地带玩法的致敬复刻，原创实现，不使用任何官方素材/名称）。

## 1. 产品定义

- 一句话：单人网页 3D 撤离射击——跳伞进场、搜刮战利品、对抗 AI 敌人、带出物资才算赚。
- 平台：桌面浏览器（Chrome/Edge/Firefox 最新版），需 WebGL2。
- 引擎：three.js 0.180（本地 npm 安装），无其他运行时依赖。
- 语言：简体中文 UI。

## 2. 核心循环

```
主菜单 → 选择装备 → 跳伞入场 → 搜刮/战斗 → 到达撤离点 → 撤离结算 → 局外仓库
                                ↘ 死亡 → 失去随身物资 → 结算 → 回仓库
```

一局目标：在限定时间（12 分钟）内搜到高价值物资并从任一撤离点撤出。
死亡惩罚：本局背包与身上装备全部丢失；保险箱（安全箱）内物品保留。

## 3. 功能需求（验收口径）

### F1 主菜单 / 局外成长
- M1 主菜单：开始行动、军备选择、图鉴说明、设置。
- M2 仓库系统：持久化于 localStorage；展示货币（Koen 币）与物品清单。
- M3 军备配置页：选主武器 + 弹药 + 甲 + 包；显示总价值。
- M4 安全箱：2×2 固定格子，局内存亡都保留。

### F2 地图「长弓溪谷」单图设计
- 约 240×240m，四类区域：
  - 农场区（谷仓、麦田、干草垛）
  - 工业区（仓库、集装箱堆场、油罐）
  - 溪谷区（中央河谷、两座木桥）
  - 防空洞区（北坡地下入口，高价值房）
- 撤离点 3 个，随机开放其中 2 个，每局随机。
- 物资点 ≥ 25 个（散件 + 容器：木箱/工具箱/医疗箱/保险柜/弹药箱）。
- 天气：黄昏光照 + 指数雾；风向常量（无风模拟需求）。

### F3 玩家控制（FPS）
- WASD 移动 / Shift 冲刺(消耗体力) / C 下蹲 / 空格跳跃 / Ctrl 缓步。
- 鼠标视角，指针锁定；滚轮切换武器槽。
- 1/2 切换主武器/副武器，3=近战，4=投掷物，G 快速扔雷，R 换弹。
- E 交互（拾取/开门/撤离确认），Tab 开背包，M 大地图，V 第三人称观战（死亡后）。
- 生命 100；部位伤害简化为整体；护甲按耐久吸收比例伤害。
- 体力条：冲刺/跳跃耗尽，站立恢复；负重降低移速。
- 跌落伤害（>4m 起）；水域：缓速 + 无法开火。

### F4 武器与战斗
| 武器 | 类型 | 射速 | 单发 | 弹匣 | 后坐力 | 特点 |
|---|---|---| tracer-bullet
|---|---|---|
| AKS-74U | 突击步枪 | 650rpm | 28 | 30 | 中 | 全能 |
| MP5 | 冲锋枪 | 800rpm | 19 | 30 | 低 | 近战强 |
| M700 | 栓动狙击 | 41rpm | 85 | 5 | 高 | 高倍镜 |
| M870 | 霰弹 | 68rpm | 9×8 pellet | 5 | 高 | 一枪糊脸 |
| M45 手枪 | 手枪 | 400rpm | 22 | 12 | 低 | 副武器 |
| 近战刀 | 近战 | - | 55 | - | - | 无声 |

- 命中判定：射线检测（hitscan），霰弹多 pellets 圆锥散布。
- 后坐力：垂直+水平随机分量，连发累积，松开缓慢回中。
- 弹道下坠：不做（hitscan 简化），但远距离衰减 10%/50m。
- 换弹动画（程序化武器下沉旋转）、腰射扩散、开镜(右键)精度提升。
- 投掷物：破片手雷（延时 2.5s，半径 7m 衰减伤害）、烟雾弹（球形粒子云 20s）。

### F5 AI 敌人（人机 + 游荡 AI）
- 三种行为态：PATROL（沿路径点巡逻）→ ALERT（听声/目视发现）→ COMBAT（交战）。
- 感知：视锥 110°、距离 40m（蹲伏×0.6、草丛×0.7）；枪声全图传播 60m 半径告警。
- 战斗：点射节奏（2-4 发停顿）、掩体寻找（简单侧移）、换弹时机、丢雷（困难度）。
- 数量：每局 14–18 个，出生点固定池 + 局内动态补员（每 90s 补 2 个直到上限）。
- 掉落：死亡后生成可搜刮尸体包（其武器+部分弹药+杂物）。
- 头盔/护甲差异影响其对玩家伤害承受。

### F6 物资与经济
- 物品数据库 ≥ 30 种：武器、弹药、甲、医疗、投掷物、杂物（卖钱用）。
- 稀有度：白/绿/蓝/紫/金 五档，颜色编码 + 价值区间。
- 容器搜刮：E 打开 → 随机 1–4 件按权重表掉落 → 进背包或留置。
- 背包容量：格子制 4×4（可升级 5×6）；每物品占格不同（1x1/2x1/2x2/4x2）。
- 医疗：绷带(回 30)/急救包(回 70)/手术包(回 100, 8s)；使用时不可移动。
- 经济：撤离成功结算 = 带出价值；局外可回购弹药和基础装备。

### F7 HUD 与反馈
- 准星（腰射扩散环）、命中标记、爆头双圈、击杀提示 feed。
- 血条/护甲条/体力条/小地图（含敌人枪声红点 2s）/罗盘。
- 弹药计数、当前武器名、交互提示（准心处 [E] 搜刮）。
- 受击方向指示器（红色扇区 1.5s）。
- 撤离点状态 HUD（开放/关闭 + 距离）。

### F8 音频
- WebAudio 程序化合成（无音频文件）：枪声（噪声+低频冲击）、脚步、换弹、
  拾取、UI 点击、心跳低血量、环境风声。距离衰减 + 声像。

### F9 设置与辅助
- 灵敏度滑条、音量、视野 FOV 60–110、画质（阴影开关/绘制距离）。
- 键位表展示。进度存档导出/导入（JSON 文本框）。

### F10 结算与留存
- 结算页：存活时长、击杀、带出物品明细、获得 Koen。
- 战绩累计：总局数/撤离率/KD/最高单局收益（localStorage）。

## 4. 非功能需求

- 加载：本地资源，首屏 < 3s（无网络依赖）。
- 性能：1080p 中画质 ≥ 50fps（iGPU 可跑）；InstancedMesh 用于植被/集装箱。
- 存档：localStorage key `delta-web-save-v1`，版本号兼容字段。
- 无外部 CDN；全部资源随仓库分发。
- 代码：ES Module，模块化拆分（engine/ world/ player/ combat/ loot/ ui/ audio/ ai/）。

## 5. 明确不做（Out of Scope）

- 多人联机、账号体系、服务器。
- 移动端触控适配。
- 骨骼动画角色模型（用胶囊+程序化姿态代替）。
- 弹道下坠与穿透。

## 6. 验收标准

1. `npx serve` 或任意静态服务器打开即玩，无 console error。
2. 一整局可完成：进场→搜刮≥5件→击杀≥1个AI→撤离成功→结算入账→重开局。
3. 死亡路径：被 AI 击杀→失去非安全箱物品→结算→回菜单。
4. 设置项即时生效并持久化。
5. 浏览器实测 FPS ≥ 50（1080p 默认画质）。
